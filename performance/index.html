Performance Report · 2026-27 Season

Baseline physical performance for 15 athletes, in one scrollable page.

At the start of the 2026 season I tested the women's basketball roster across four physical-performance domains. This report turns those raw numbers into a ranked, simple document the coaching staff can use as a shared reference for the rest of the year. The document is rendered automatically through an automated update which pulls data from source API's and renders the document as-is.

The question

Where does every athlete currently stand on the physical qualities that matter for basketball — vertical force production, explosive output, reactive strength, and absolute lower-body strength — and who sits above or below the group reference on each one? The answer has to be legible to a head coach on a quick glimpse.

The data

Four tests collected over a preseason testing block, with the Epley estimated 1RM pulled weekly from the squat program, a simple way to explain the progressive overload of the athletes. Later detail could be added to further explain estimated 1RM using velocity-based technology via the Perch sensors:

  • IMTPIsometric mid-thigh pull. Peak force expressed relative to body mass — a lower-body isometric-strength ceiling.
  • SJSquat jump. Concentric-only vertical performance, isolating the push without stretch-shortening-cycle contribution.
  • CMRJCountermovement jump followed by a rebound jump. Captures both the countermovement vertical and the reactive strength of the rebound.
  • Estimated 1RM back squatWeekly estimate from the training programs accomplished work, converted to a per-kilogram-of-bodyweight relative figure for ranking.

The approach

Everything is written in R and rendered through R Markdown to a single-file HTML document. Each test gets a ranked table (gt), a distribution plot (ggplot2), and a short interpretation. The file ships as one HTML attachment — no server, no login, no dashboard to log into — which is how coaching staff actually consume reports in practice.

What's in the report

  • Team Performance RankingOverall ranked view across the four tests
  • IMTP Relative Force RankingPer-kilogram peak force, athlete-by-athlete
  • Relative Back Squat StrengthWeekly estimated 1RM, normalized to body mass
  • Relative Strength DistributionWhere each athlete sits in the group distribution
  • Metric DefinitionsPlain-language reference for staff who are new to the tests

All athlete identifiers have been removed for public display. The report preserves the structure, visualizations, and interpretations shared with the coaching staff.
