Session RPE Report · 2026–27 Season

sRPE as a performance signal, not just a load log.

Session RPE is often collected and rarely read. This report takes every session the team has logged so far this season and renders it as weekly load trends, acute-vs-chronic ratios, team-vs-coach comparisons, and — the piece most load reports stop short of — correlation between daily load and the next day's countermovement rebound jump performance.

The question

If we're going to ask every athlete to score every session, the output has to be worth more than a line in a spreadsheet. Two things specifically: can the coaching staff see week-to-week how hard the group has been pushed; and does the training load we've imposed show up in the jump performance we measure a day or two later. The second question is where most sRPE reporting stops — this one tries to answer it.

The data

Every logged session for the 2026–27 season to date, broken into focus, intensity (sRPE), load (sRPE × duration), and separated RPE legs / RPE lungs ratings so the report can distinguish neuromuscular from cardiovascular stress. Jump data is pulled from the parallel countermovement rebound jump testing protocol and aligned by date.

The approach

R Markdown report, rendered as a single interactive HTML file for the coaching staff. Each section is a sport-science-standard load metric (ACWR, EWMA, monotony & strain) rendered as a Plotly chart with the team and individual athletes selectable. The correlation sections use rolling windows at both the athlete-day and team-week level so the staff can see signal at the level they make decisions at.

What's in the report

  • Session Focus DescriptivesHow much of each session type the team has done
  • Athlete-Level DistributionsPer-athlete sRPE / RPE legs / RPE lungs spread
  • Season Phase ComparisonPreseason vs in-season load profile
  • Weekly Load TrendsGroup sRPE week-over-week with jump height and rebound-DRI overlay
  • EWMA Acute vs Chronic LoadExponentially-weighted moving averages for load monitoring
  • Acute:Chronic Workload RatioACWR with sweet-spot and danger-zone shading

  • AM vs PM Session AnalysisPaired within-day differences and prior-day correlation to next-day RPE
  • Load vs Performance Correlation MatrixCorrelation between daily load metrics and next-day CMRJ performance, at both athlete-day and team-week resolutions
  • Cumulative Team LoadSeason-to-date totals

A companion report — Part 2

Part 2 picks up where Section 6 of the main report left off. The main report correlates two hand-picked CMRJ outputs against weekly load; Part 2 pulls every CMRJ metric the testing system records, screens each one through a within-athlete reliability filter (CV% ≤ 10%, the sport-science convention for acceptable or excellent), and runs the surviving metrics through a broader correlation panel against weekly sRPE, RPE Legs, RPE Lungs, and ACWR. It closes with a linear mixed-effects prediction model with athlete as a random intercept and a quadratic term on ACWR, so the data can speak to whether the load panel actually predicts jump outcomes or only correlates with them — and which load lever is the strongest.

What's in Part 2

  • Reliability Pre-FilterWithin-athlete CV% screen across every available CMRJ metric, with excellent / acceptable / noisy tiers
  • Sign-Flipped Negative MetricsCountermovement depth and eccentric peak velocity re-oriented so higher = better uniformly across the panel
  • Correlation HeatmapsReliable CMRJ metrics vs weekly load, at both athlete-week and team-week resolutions
  • Mixed-Effects PredictionOne model per reliable CMRJ metric, linear + quadratic ACWR, athlete as random intercept, with marginal and conditional R² per target
  • Summary of FindingsAuto-generated staff-facing read of the strongest signals and the best-predicted jump outcome this season

All athlete identifiers have been removed for public display in both reports. The analyses preserve the structure, visualizations, and findings shared with the coaching staff.
